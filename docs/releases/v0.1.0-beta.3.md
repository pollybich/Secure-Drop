pollyDrop: гостевой обмен файлами и текстом в светлом интерфейсе с матовым стеклом.

- Сервис pollyDrop для временной передачи файлов и текста без регистрации.
- Курсивная «p», матовое стекло, адаптивная типографика, баннеры и фавикон.
- Полные русский и английский интерфейсы, переключатель RU / EN и сохранение ручного выбора.
- Первое открытие выбирает русский для IP России и английский для остальных стран. Страна определяется локально по базе DB-IP Lite; IP посетителя не отправляется провайдеру геолокации.
- По умолчанию 1 час хранения, максимум 2 дня. Удаление после последнего получения или срока — по первому условию.
- Установка готовых сборок без компиляции Node.js на сервере. Обновление проверяет JavaScript, который реально отдаёт сайт.
- Перенос существующей локальной установки в пространство pollydrop-public: холодная копия БД и файлов, сохранение ключей, переименование БД и роли. Исходные volumes остаются для восстановления.
- Сайт: https://drop.pollybich.ru.

Установка и сохранение данных существующего сервера: [инструкция](https://github.com/pollybich/pollyDrop/blob/main/deploy/server/README.md). Для существующей установки используется новый checkout с копией `.env`; последующие обновления выполняет `update-debian.sh`.

Перед применением создайте DNS-запись `drop.pollybich.ru` на свой сервер. Обновление переносит данные и запускает HTTPS для нового имени. Существующие переданные ссылки используют прежний домен; отправитель может передать тот же путь `/s/...` на новом домене, пока срок и лимит действуют. Автоматический редирект старого домена не создаётся.

Этот предварительный выпуск включает серверный JAR с базой стран, frontend-архив, скриншоты и SHA256SUMS. Шифрование серверное, не сквозное; метаданные и резервные копии имеют отдельный жизненный цикл.

**English**

pollyDrop provides temporary file and text sharing without an account, with an italic p mark and a responsive frosted-glass interface.

- Complete RU / EN interface with a saved manual preference. Local IP country lookup selects Russian for Russia and English elsewhere; no visitor IP is sent to a geolocation provider.
- One-hour default, two-day maximum. Content is deleted on expiry or the last permitted delivery, whichever occurs first.
- Checked, prebuilt server/frontend assets; updates verify the JavaScript actually served by the site.
- Existing installations can migrate with their encryption keys, passwords, deadlines and download counts preserved. See the [deployment guide](https://github.com/pollybich/pollyDrop/blob/main/docs/en/DEPLOYMENT.md).

Set up DNS for `drop.pollybich.ru` before applying the server configuration. Assets include the server JAR with a country database, frontend archive, screenshots and SHA-256 checksums. Encryption is server-side; metadata and backups have separate lifecycles.
