# Требования первой версии

Реестр основных функций и критериев приёмки pollyDrop. Это целевой объём первой версии; текущая бета включает гостевой обмен, а аккаунты и корпоративные функции остаются в плане. Выполненные пункты отмечены в [ROADMAP](../ROADMAP.md). `Must` — обязательное для первой версии; `Should` — важное улучшение, включённое в план.

## Цели продукта

| ID | Цель |
| --- | --- |
| B01 | Временная передача файлов и текста с управляемыми условиями доступа. |
| B02 | Защита содержимого, паролей и операций управления. |
| B03 | Отзыв доступа и автоматическое удаление недоступных данных. |
| B04 | Воспроизводимое развёртывание и проверяемая реализация. |
| B05 | Публичное использование и внутреннее размещение в компании. |

## Правила доступа

- Владение аккаунта или право по гостевому токену управления проверяется сервером, а не только интерфейсом.
- Сначала проверяются состояние, срок, пароль и возможность выдачи.
- Резервирование лимита должно быть атомарным.
- Успешная отправка всего содержимого фиксируется сервером, а не произвольным подтверждением клиента.
- При обрыве слот освобождается только после остановки прежней выдачи. Пока слот занят, повтор не запускается параллельно.
- Восстановление зависшего резервирования должно исключать продолжение прежнего потока; простой таймер не должен создавать две активные выдачи.
- Повтор не восстанавливает истёкшую или отозванную передачу.
- Фоновая очистка не заменяет проверку доступности при запросе.
- Просмотр страницы получения отделён от запроса содержимого.
- Контроль доступа не запрещает получателю сохранить уже полученную копию.
- Повтор после обрыва не гарантирует, что ранее отправленные байты не сохранились у получателя.

## Готовность задачи к разработке

- Есть требование, ценность, приоритет и проверяемые критерии.
- Определены ошибки, границы, зависимости и условия безопасности.
- Понятны результат и границы работы.
- Подготовлены данные и способ проверки.

## Готовность результата

- Критерии приёмки выполнены, ошибки и границы проверены.
- Тесты критической логики проходят.
- Секреты и содержимое не попадают в журнал или репозиторий.
- Миграции, API и инструкции обновлены, если изменение их затрагивает.
- Блокирующие дефекты закрыты.

## За границами первой версии

Постоянное облачное хранение, нативные мобильные приложения, корпоративный SSO, индивидуальные интеграции и S3/MinIO не входят в первую версию.
